This document contains a comprehensive collection of datasets, research documentation, Python programming scripts, and experimental results for the undergraduate thesis entitled “Performance Comparison of YOLO12 and YOLO26 for Recyclable Waste Classification Under Different Lighting Conditions.”

The purpose of this documentation is to organize and present all materials used throughout the research process, from dataset preparation and experimental implementation to model evaluation and performance analysis.

The documentation consists of the following sections:

1. Research Dataset

Contains recyclable waste images categorized into three classes: Glass Bottles, Plastic Bottles, and Cans. The dataset includes variations in object rotation angles and three different lighting conditions: dim, medium, and bright. These images are used as the primary data for training and evaluating the detection models.

2. Scenario A and Scenario B

Contains the experimental configurations and dataset arrangements used in the research. Both scenarios are designed to examine and compare model performance under different experimental conditions. Each scenario provides a basis for evaluating the capabilities of YOLO12n and YOLO26n.

3. Research Logbook

Contains records of research activities, progress updates, experimental procedures, supervisor feedback, and documentation of the research development process. It serves as a chronological record of the work conducted throughout the study.

4. Python Programming Scripts

Contains Python scripts developed and implemented during the research. These scripts are used for image processing, lighting condition adjustments, dataset organization, experimental execution, object detection, and evaluation metric calculations. Python is also used to automate several processes and organize experimental outputs for further analysis.

5. YOLO12n and YOLO26n Detection Results

Contains the detection and evaluation results of both models under Scenario A and Scenario B. This section includes detection outputs, evaluation tables, performance metrics, and comparisons based on object classes and lighting conditions. The evaluation focuses on metrics such as precision, recall, F1-score, accuracy, and mean Average Precision (mAP).
